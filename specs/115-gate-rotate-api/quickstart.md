# Quickstart 115

Log in as `super_admin` → `/admin` → click "Section gates" → land on `/admin/gates` showing five gate cards (mentorship, observation, admin, tkt, ttt) each with stats (last rotated, active grants, attempts/failures in 30d). Click "Rotate password" on the mentorship card → confirm in the native dialog → an amber reveal block appears with the new 12-character plaintext password + "Copy" + a recipient `<select>` + "Share via WhatsApp". `audit_log` now has a `gate.password.rotated` row with `entity_id='mentorship'`, `metadata.version=N+1`, `metadata.grantsInvalidated=<count>`. Every mentorship-gate user is logged out of the gated section and must re-unlock at `/gate/mentorship` with the new password. Click Share → confirm → a new tab opens at `https://wa.me/<recipient-phone>?text=[GML%20LMS]%20New%20mentorship%20gate%20password:%20<plaintext>...`; an audit row `gate.password.share_initiated` lands without the plaintext in metadata. Log in as `programme_admin` instead → `/admin/gates` redirects to `/forbidden`; a direct `POST` to `/api/admin/gates/mentorship/rotate` returns `403 {error: "forbidden"}`.

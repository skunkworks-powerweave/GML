# Research 114
Drizzle's `ilike(col, "%value%")` is the right cheap-text-match for varchar columns and degrades to runtime error on non-text columns (e.g. uuid) — keeping the v1 contract "filter on display columns" means we only ever filter on columns the entity author exposed as visible. URL-driven filter state matches the JSX prototype's URL-shareable filter discipline (admin.jsx::AdminTable read `q.get("filter[...]")` from the URL on mount). Native `window.confirm()` is intentional for v1 — zero new components, keyboard accessible, works on mobile; can be swapped for the JSX ConfirmModal later without touching the server action. Reusing one `RowForm` for create + edit (vs. a sibling `edit-form.tsx`) keeps the Zod `formSchema` the single source of truth for both paths — exactly matches the spec 022 CSV pattern that already validates via the same schema.
